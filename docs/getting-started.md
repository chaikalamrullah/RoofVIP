## 1. Start from the release, not from “latest”

For reproducible experiments, record the exact RoofVIP version you use. The [Dataset]({{ '/dataset/' | relative_url }}) page lists released and provisional versions separately.

## 2. Follow release relationships

Some releases extend an earlier release rather than replacing it. For example, v1.0.1.0 adds elevation products aligned to the identifiers of v1.0.0.0.

## 3. Preserve identifiers across modalities

RoofVIP identifiers are intended to keep corresponding imagery, elevation products, and vector geometry traceable across compatible releases.

## 4. Record the benchmark protocol separately

When using the future RoofVIP Benchmark, report both the dataset release and benchmark protocol version.
