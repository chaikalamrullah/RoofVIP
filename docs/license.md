## RoofVIP license

RoofVIP is released under the **Creative Commons Attribution 4.0 International License (CC BY 4.0)** unless a release page explicitly states otherwise.

## Source-data attribution

The Munich releases use geodata products provided by the **Bavarian Surveying Administration (Bayerische Vermessungsverwaltung)** through Bavarian Open Geodata. Users should preserve the source attribution required for the data products incorporated into the relevant RoofVIP release.

## Release-specific terms

Always check the release page and accompanying archive metadata before redistribution or publication, particularly when future RoofVIP versions incorporate additional providers or geographic regions.
