## Overview

RoofVIP v1.0.0.0 is the original Munich release. It combines **20 cm very-high-resolution RGB orthophotos** with manually created roof annotations intended for geometry-aware building-roof research.

## Data content

- Tiled aerial image patches centered on individual buildings.
- RGB imagery derived from DOP20 RGB data.
- Manual roof annotations following LoD2-oriented roof-plane geometry.
- Polygon annotations stored in NumPy (`.npy`) format.
- Stable RoofVIP building identifiers for correspondence with compatible extensions.

## Intended research use

The release is designed to support roof segmentation, vectorization, structured geometry learning, and roof reconstruction experiments.

## Source imagery

The source imagery is provided by the **Bavarian Surveying Administration (Bayerische Vermessungsverwaltung)** through Bavarian Open Geodata.
